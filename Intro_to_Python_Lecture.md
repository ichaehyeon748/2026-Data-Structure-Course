# Intro to Python

## Notion
Python is an intuitive, high-level, and versatile programming language that emphasizes readability. It is an interface-oriented language that supports Object-Oriented Programming (OOP), treating data structures as classes and objects

## Core explanation
- Data Types: Python provides several built-in types, including integers (int), floats (float), strings (str), and lists (list).
- Classes and Objects: Users can define their own data structures using the class keyword. The __init__ function is a special method that automatically executes to initialize a new object.
- Self Parameter: Within a class, self is used as a reference to the current instance of the object, allowing access to its attributes.
