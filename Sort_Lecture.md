# Sort

## Notion
Sorting is the process of arranging elements in a list into a prescribed sequence, such as numerical or alphabetical order. It is essential for optimizing other operations like searching.

## Core explanation
- Basic Algorithms: These include Selection Sort (repeatedly finding the minimum), Insertion Sort (placing elements in their correct position), and Bubble Sort (swapping adjacent items), all typically having O(n^2) time complexity.
- Advanced Algorithms: More efficient methods include Merge Sort and Quick Sort, which use a divide-and-conquer strategy to achieve O(nlogn) performance.
- Stability: A sorting algorithm is considered "stable" if it preserves the relative order of elements with equal keys. Insertion, Bubble, and Merge sorts are stable, while Selection and Quick sorts are not.
- Shell Sort: An improvement over insertion sort that compares elements at a specific "gap" to speed up the process.
