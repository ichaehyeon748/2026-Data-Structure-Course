# Tree

## Notion
A tree is a hierarchical non-linear data structure used to represent and organize data through a root node, branches, and leaf nodes. Unlike linear structures like arrays or stacks, it organizes data in a parent-child relationship.

## Core explanation
- Binary Tree: A specific type of tree where each node has a maximum of two children, known as the left and right child.
- Binary Search Tree (BST): A sorted tree where the left subtree contains keys smaller than the root, and the right subtree contains keys larger than the root.
- Traversal: Methods to visit all nodes in a tree, including Depth-First Search (Preorder, Inorder, Postorder) and Breadth-First Search (Level Order).
- Performance: The efficiency of operations like search, insertion, and deletion in a BST is generally proportional to the height of the tree, h.
