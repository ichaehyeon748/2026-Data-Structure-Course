# Graph

## Notion
A graph consists of a set of vertices (nodes) and edges that represent connections or relationships between those objects. It is a versatile non-linear structure used for pathfinding, social media analysis, and network mapping.

## Core explanation
- Types of Graphs: Graphs can be undirected (bi-directional edges), directed (one-way edges), or weighted (edges with assigned costs or distances).
- Representations: They are typically represented using an Adjacency Matrix (a 2D array) or an Adjacency List (linked lists for each vertex).
- Traversal: Standard algorithms to explore graphs include Depth-First Search (DFS), which explores as far as possible along branches, and Breadth-First Search (BFS), which visits nearest nodes first.
- Key Algorithms: Important graph operations include finding a Minimum Spanning Tree (MST) using Kruskal’s or Prim’s algorithms and finding the shortest path via Dijkstra’s algorithm.
