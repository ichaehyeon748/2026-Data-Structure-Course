# Intro to Data Structure

## Course Description
Data structures serve as fundamental frameworks for organizing and storing data within computing systems to use the data efficiently and effectively. In this course, students will explore various types of data structures, ranging from basic linear structures such as arrays, linked lists, stacks, and queues, to more complex non-linear structures like trees and graphs. Furthermore, we study various algorithms by utilizing various data structures we learned so far which are essential for performing operations or to solve problems utilizing data structures efficiently. Students will learn how to design and implement algorithms for tasks such as sorting, searching, and constructing minimum spanning trees.
We provide real-world examples to provide the practical applications and importance of the concepts being taught. Students will gain practical experience in implementing data structures and algorithms using Python programming language. Through a combination of hands-on programming lab sessions, assignments, projects, and discussions, students will develop a robust understanding of data structure concepts and their role in optimizing data manipulation and analysis processes.
