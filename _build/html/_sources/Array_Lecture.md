# Array

## Notion
An Array is a collection of items of the same data type stored at contiguous memory locations.

## Core explanation
- Static Data Structure: Arrays are static, meaning they have a fixed size that cannot be changed once created.
- Efficiency: Element access is extremely fast (O(1)) because items can be located directly using their index.
- Operations: Insertion and deletion are relatively slow (O(n)) because they require "shifting" existing elements to the right or left to maintain the contiguous structure.
