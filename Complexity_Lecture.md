# Complexity

## Notion
Complexity Analysis provides a theoretical estimation of the time and space resources required to execute an algorithm, specifically focusing on how these requirements change as the input data size (n) grows.

## Core explanation
- Time Complexity: This measures the number of operations (f(n)) an algorithm performs rather than its actual execution time, making the analysis independent of specific hardware or software environments
- Asymptotic Notations: These are used to theoretically define the limits of performance:
    - Big O (O): Represents the upper bound, or the worst-case complexity
    - Big Omega (Ω): Represents the lower bound, or the best-case complexity
    - Big Theta (Θ): Represents the tight bound, used when the upper and lower bounds grow at the same rate
